# 🌍 COVID-19 Data Analysis & Dashboard

This project involves the exploration and visualization of COVID-19 data using Python. The aim is to understand the trends in daily and cumulative cases, deaths, and active cases across countries. A clean, interactive dashboard is built using Streamlit to help users analyze trends efficiently.


## 🎯 Objectives

- Analyze global and country-level COVID-19 data from **Worldometer**
- Understand patterns in cumulative and daily cases, deaths, and active cases
- Identify countries with significant changes or trends
- Visualize the data using graphs and interactive filters

- Key Insights
Several countries experienced steep rises at different points in time

Daily new cases and deaths often lag behind cumulative patterns

Some countries show inconsistent reporting (NaNs or sudden spikes)

Visualization helps uncover regional and temporal trends clearly

🔍 Reflections
This project showcased the power of data visualization in understanding complex health data. Using Streamlit for the dashboard provided an intuitive way to share insights interactively. Handling real-world data also highlighted the importance of data cleaning, handling missing values, and presenting results clearly.
